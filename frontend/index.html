Behind The Portfolio

How a message becomes a real notification.

A closer look at the full-stack contact workflow running behind this site.

01Contact Form

The browser trims the input, checks required fields and validates the email before making a request.

02API Request

The form sends a JSON POST request to /api/contact on the deployed Express server.

03Validation

The controller checks that name, email, subject and message are present before continuing.

04MongoDB

A Mongoose model stores the contact with trimming, length limits and automatic timestamps.

05Email Delivery

Resend sends the notification to the configured destination and reports failures back to the API.

Engineering decisions

Validation happens in both the browser and backend. The database schema adds a second boundary with required fields, trimming and maximum lengths, while the API returns clear success and error responses.
